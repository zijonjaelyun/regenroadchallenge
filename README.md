# REGEN ROAD CHALLENGE v14 — 4× RUSH / FIVE STAGE EDITION

학교 축제용 회생제동 레이싱 게임. 브라우저에서 `game.html`을 직접 열거나 Streamlit으로 실행할 수 있습니다.

## v14: 요청사항 반영

- **체감 이동속도 4배:** 물리 엔진의 실제 거리 `state.x`와 화면에서 사용하는 시각 거리 `renderState.x = 4 × state.x`를 분리했습니다. **도로, 차선, 가드레일, 나무, 바위, 갈매기, 물보라, 선인장, 오아시스, 눈나무, 표지판 모두 같은 4배 월드 좌표를 사용합니다.** 속도계와 제동거리 계산은 실제 게임 거리 단위를 유지합니다. 이 4배는 *시각 효과*이며, 화면에 표시되는 km/h를 임의로 4배 높인 것이 아닙니다.
- **FPS 안정화:** 가드레일 렌더링 주기와 구름 블러를 최적화하고 고해상도 화면에서는 내부 해상도를 적절히 제한합니다. 프레임이 느린 경우 실제 경과 시간을 물리 연산의 작은 단계로 나누어 처리하므로 저하된 FPS가 게임의 물리적 흐름까지 지나치게 늦추지 않습니다.
- **5개 난이도 차별화:** 코스 중심선의 곡선 공식 자체를 맵별로 다르게 하고, 그립·회생 전력·배터리 사용·횡풍·내리막·감속 게이트 수를 차등 적용했습니다.
- **폭풍 맵의 회전 복귀 버그 수정:** 카메라 조향 회전을 제거하고 매 프레임 캔버스 변환 행렬을 단위행렬로 초기화합니다. 자동차 방향 전환은 그대로 유지합니다.
- 기존 화면 흐름(PLAY → 이름 → 맵 선택 → 튜토리얼 → 3·2·1 → 주행 → 결과 → 랭킹), 원리·방정식 보기, 랭킹, 점수 공식, 낙하 연출을 유지합니다.

## 실행

1. ZIP을 해제합니다.
2. 바로 플레이: `game.html`을 Chrome 또는 Edge에서 엽니다.
3. Streamlit 배포: 프로젝트 루트의 `app.py`, `game.html`, `requirements.txt` 및 `assets/`를 GitHub에 업로드합니다. Streamlit Cloud의 Main file path는 `app.py`입니다.

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 조작

- `W` 또는 마우스 왼쪽 버튼 누르고 있기: 액셀
- `S` 또는 마우스 오른쪽 버튼 누르고 있기: 브레이크 및 회생제동
- `A`/`D` 또는 `←`/`→`: 좌우 조향
- 오른쪽 위 `Ⅱ`: 일시정지

## 점수 및 교육적 한계

- 점수는 **완주 시 남은 배터리 55점 비중 + 완주 시간 45점 비중**으로만 결정됩니다. 회생량 보너스는 없습니다.
- 가속 시 배터리 소비 %와 회생제동 시 배터리 회복 %는 실제 전기차보다 과장한 **게임용 게이지**입니다. 그래프/수식 설명에서는 `P = η × Fregen × v` 등의 운동 및 에너지 계산과 게임용 게이지를 구별해 주세요.
- 마찰·회생제동 수치와 4배 시각 움직임도 실제 차량 테스트와 구별해야 합니다.
- v14부터 물리·난이도 조건이 바뀌었으므로 브라우저 로컬 랭킹은 `regenRoadV14Ranking`에 별도로 저장됩니다.

## 시험 사항

수치 기반 자동 조향·제동 정책으로 전 맵 완주를 확인했으며 액셀만 유지하는 경우 전 맵 첫 감속 게이트에서 실패했습니다. 브라우저 버튼/화면 전환 20개 항목, 5개 맵의 캔버스 렌더링, 폭풍 맵 조향 복귀 검사를 실행했습니다. 테스트용 자동 주행은 인간 플레이의 체감 난이도를 보장하지 않습니다. 자세한 내용은 `VALIDATION.md`에 있습니다.
